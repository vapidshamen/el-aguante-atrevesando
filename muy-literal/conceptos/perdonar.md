# perdonar

se usa la misma palabra (ἀφίημι) para significar:
- despedido
- soltado
- perdonado
- descargado
- echado

#### ἀφίημι

ἀπό (desde/despues) + ἵημι (a echar/tirar/enviar/mandar)

depende mucho del contexto, pero literalmente, significa "despues de tirar/mandar/enviar"
